## 安装

1. 先安装浏览器脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)
2. 点击 [douban-rating-master-lite.user.js](douban-rating-master-lite.user.js) 原始文件链接，Tampermonkey 会弹出安装页面
3. 安装后访问任意豆瓣影片页（如 <https://movie.douban.com/subject/36828393/>）即可看到效果

### 布局与显示优化

- **影视名称行追加 IMDb 编号**：纯文本格式，形如 `人性本兽.Animals.2026.tt31049299`
- **评分列重排**：客观评分置于豆瓣评分上方；其他平台评分统一移到豆瓣评分（含"好于%"）下方
- **评分卡自适应列数**：不超过 2 个评分一列，超过 2 个自动两列，避免右栏被撑得过长
- **全新紧凑布局**（本 fork 核心改动）：
  - 消除"影片信息 → 想看/看过 → 剧情简介"之间的大片空白
  - 原理：右栏评分列改为右浮动并补偿位移保持原位，解封双栏容器（去浮动/去 clearfix 撑高），后续内容沿左栏底部自动环绕评分列排布
  - 左栏底部与想看行之间保留 28px 呼吸空间（脚本内常量 `COMPACT_GAP` 可调）
  - 评分卡异步到达导致右栏变高时自动重排，空白消失后自动还原，不破坏豆瓣原有布局

### 加载可靠性优化

- 全平台网络请求统一：**超时、指数退避重试、并发合并**（原版仅有简单重试）
- 排行榜（MRQE、FilmAffinity 等）加载逻辑修复
- 烂番茄新鲜度&爆米花指数、Metacritic 影评人&用户双评分、Letterboxd 加载逻辑优化
- FilmAffinity 直连被 Cloudflare 拦截（403）时，自动切换阅读代理通道
- 剧集播出日历加载优化

### 保留的核心功能

- 全球评分聚合：IMDb、烂番茄（新鲜度&爆米花）、Metacritic（影评人&用户）、TMDB、Letterboxd、Allocine、AniList、Bangumi、MyAnimeList、MyDramaList、MRQE、NeoDB
- 客观评分智能加权算法（按作品主场调权 + 票数置信度）
- 各平台排行榜（含 FilmAffinity）
- 剧集播出日历
- 一键复制影片资料（含完整演职员表及获奖列表）
